# Button

One solid milk block per screen; everything else is an outline or text.

- `dd-pill`: the solid milk block, one per screen, full width above the tab bar on Brew. Verb first: Start, Stop, Log brew · 2:58.
- `dd-pill dd-pill-ghost`: a 1.5px outlined square beside it (Reset), icon only with an aria-label.
- `dd-btn dd-btn-go` / `dd-btn`: actions at the end of a sheet section, side by side. `dd-btn-red` for destructive.
- `dd-again`: a small outlined button on a journal row.
- `dd-link`: in section headers and sheet headers (Cancel, Save, Adjust).

Press: 97% on pointer-down in 100ms, spring back softly. Square corners always.
