# RecipeGrid

Six numbers in a 3 × 2 grid: the recipe at a glance.

Order is fixed: Coffee, Water, Ratio / Grind, Temp, Bloom (or Time on a finished brew). Label in `caption`, value at 21px with tabular figures, unit at 14px in `text-muted`. The grind unit follows the grinder (clicks, dots, none for the Ode). A footnote says where the recipe came from.
