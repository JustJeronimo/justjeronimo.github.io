# CupLabel

The signature: every logged brew gets its own label, like a release.

- Top: colour blocks in the taste colours of the brew's tags, width by count. All-fault cups are grey.
- Body on #121212: brew number and date in small mono capitals, bean name in serif italic, the brew code, the rating in milk stars.
- Square corners. Share size 1080 × 1350; in-app 300px wide.
