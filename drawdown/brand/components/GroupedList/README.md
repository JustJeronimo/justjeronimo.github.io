# GroupedList

iOS inset grouped list: the backbone of every screen.

- `dd-sec` above (13px capitals), `dd-group` container, `dd-cell` rows, `dd-foot` below.
- Rows: optional `dd-thumb` (photo or taste colour), `dd-cell-main` with title and up to two `dd-cell-sub` lines, then a value or `dd-chev`.
- Hairlines are inset 16px. Pressed rows flash a light overlay with no delay.
- Action rows are a single underlined title in `text`; destructive rows in `alert`.
