# BrewCode

The whole recipe on one line, in mono: dose/water · G + grind · temp · time · rating.

Grind keeps the grinder's own notation (G21 clicks, G0.6.7, G4.1). No units inside the code; separators in `text-muted`. Above it, `dd-code-s` for the brew number and date in capitals. Use codes where a recipe must be copied exactly; write sentences in instructions.
