# TasteChip

Tasting tags, coloured by taste family once selected.

Families: acid (juicy, bright), fruit (fruity), floral, sweet (sweet, balanced), body (chocolatey, heavy) and off (sour, bitter, astringent, thin, muddy) in grey. Unselected chips are `dd-taste-idle`. Ink text on every colour. These colours feed the cup label.
